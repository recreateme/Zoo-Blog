## 1、算法选择

首先，看一下不同场景下的最短路径算法选择：

![tongyi-mermaid-2026-07-25-163616](/images/posts/shortest-path-algorithms/algorithm-selection.png)



> 1、以上算法没有区分有向图/无向图，以上算法两种情况均适用。有向图的检测方向有部分额外的限制，具体表现在图节点的距离邻接矩阵中即为非对称矩阵，如节点**n1**到节点**n2**距离可能为3，**n2**到节点**n1**距离为正无穷。
>
> 2、针对DAG 图（有向无环图），**拓扑排序 + DP**可以在复杂度**O(V+E)**下解决单源最短路径问题（**SSSP**），即使带负权边也没问题（因为无环）。具体做法见下文「3、经典算法讲解 (7) 拓扑排序 + DP」。
>
> 3、当单源、非负权、且存在明确目标点时，**A\*** 是 Dijkstra 的启发式加速版本：通过设计一个合理的启发函数，让搜索优先朝目标方向扩展，从而减少无效探索，具体见下文「3、经典算法讲解 (6) A\* 算法」。

## 2、算法分类

### （1）按目标最短路径数：单源最短路径（SSSP） VS 多源最短路径（APSP）

1、**单源最短路径（SSSP）**：计算的是从**一个固定的、指定的起点（源点）** 到图中**所有其他节点**的最短路径。

**问题**：求从点 **A** 到图中所有点（B, C, D, E...）的最短距离。

**算法代表**：Dijkstra, Bellman-Ford。

**类比**：在地图App里，你设置**你的家**为起点，然后查询到你公司、你朋友家、你父母家的最短距离。你只关心从一个点（你家）出发的所有路线。

![最短路径](/images/posts/shortest-path-algorithms/sssp-overview.png)

**2、多源最短路径（APSP）**：计算的是图中**任意一个节点**到图中**任意另一个节点**之间的最短路径。它要算出所有可能的节点配对（Point Pairs）之间的最短路径。

**问题**：求任意两点（A到B, A到C, A到D, B到C, B到D, C到D...）之间的最短距离。

**算法代表**：Floyd-Warshall。

**类比**：如图你拿到一张完整的**城市间距离表**（就像以前地图册后面的里程表）。这张表告诉你任意两个城市（比如北京到上海、广州到成都、武汉到西安...）之间的最短距离。它已经预先计算好了所有点与点之间的关系。

### （2）按图的方向性：有向图 VS 无向图

这个分类主要关注算法是否能处理不同方向的图。

| 特性       | 说明                                                         | 适用算法                                                     |
| :--------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **有向图** | 边具有方向性（如 `u -> v`）。算法的每一步松弛操作都需要遵循边的方向。 | **几乎所有通用最短路径算法**都天然支持有向图，如：Dijkstra, Bellman-Ford, Floyd-Warshall, BFS（在无权图中）。 |
| **无向图** | 边没有方向（如 `u - v`），相当于两条方向相反的有向边 `(u, v)` 和 `(v, u)`。 | 同样，**几乎所有通用算法**都支持无向图。处理时只需将一条无向边当作两条反向的有向边即可。 |

**重要说明**：

- **无向图中的负权边**：需要特别注意。一条负权无向边等价于两条负权的有向边，**并且很容易形成一个负权环**（例如 `u -> v -> u` 的路径长度为 `2 * weight`，如果为负则构成环）。因此，在无向图中使用能处理负权的算法（如Bellman-Ford）时，其主要目的往往是**检测图中是否存在任何负权环**。

补充：**负权环**

![负权环](/images/posts/shortest-path-algorithms/negative-cycle.jpg)

负权环 = 环路里 **各边权重之和为负数** 的闭合路径。
如上图，节点0到节点1为-1，但节点1无法返回节点0，不会构成负权环。但如果上图它带来的核心问题是 **“最短路径”不再存在**——绕环一圈总长度变小，可无限循环下去，算法陷入死循环或返回错误结果。

具体危害：

1. 算法层面
   - Bellman-Ford 检测到第 V 次仍能松弛 ⇒ 抛出“存在负环”异常
   - Dijkstra 等贪心类算法 **无负环检测机制**，会无限绕环，内存爆掉或 CPU 100%
   - Floyd-Warshall 结果全为 `-∞`（负环节点到所有点距离被不断更新）
2. 业务层面
   - 网络路由：RIP/IGRP 把“负环”当成更短路径，造成 **路由振荡、黑洞**
   - 金融套利：负环对应 **套利机会**（三角套利），需单独提取并报警，而非当最短路径用
   - 调度/定价：负环代表 **成本可无限降低**，模型失去可行解
3. 数学层面
   - 破坏“最优子结构”——子路径不再最优，导致动态规划、贪心策略失效。

### （3）按边的权重：负权图 vs. 正权图

| 特性                    | 说明与影响                                                   | 适用算法                                                     | 不适用算法                                                   |
| :---------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **正权图** (或非负权图) | 所有权重 `w >= 0`。这是最理想的场景。**贪心策略有效**，可以找到最优解。 | **1. Dijkstra算法**：**最佳选择**，效率高。 <br />**2. BFS**：无权或等权图下的特例。 <br />**3. Bellman-Ford**：可用但慢。 <br />**4. Floyd-Warshall**：可用。 | 无                                                           |
| **负权图** (无负权环)   | 图中存在权重 `w < 0` 的边，但**不存在负权环**（即环上总权重为负的环）。最短路径存在。 | **1. Bellman-Ford算法**：**经典选择**，可检测负权环。 <br />**2. SPFA**：BF的优化，平均性能好。 **3. Floyd-Warshall**：可计算所有点对距离。 | **Dijkstra算法**：**完全失效**。贪心策略无法保证正确性，可能得出错误结果。 |
| **含负权环的图**        | 图中存在负权环，且**源点可达该环**。最短路径**不存在**（因为可以无限绕环使路径长度趋于负无穷）。 | **Bellman-Ford / Floyd-Warshall**：主要用于**检测**图中是否存在这样的环。 | **所有寻求最短路径长度的算法**（因为问题本身无解）。         |

### （4）特殊图结构：DAG（有向无环图）

除了权重、方向性这两个维度，**图本身是否有环**也是选择算法的重要依据。当图是**有向无环图（DAG）**时，不需要用通用的 Dijkstra / Bellman-Ford，而是可以用**拓扑排序 + DP**在 **O(V+E)** 内解决单源最短路径问题——这是所有单源算法中理论上最快的一种，且天然支持负权边（因为无环，不存在"无限绕环变小"的问题）。具体算法见下文「3、经典算法讲解 (7)」。

## 3、经典算法讲解

### （1）BFS算法

**1、算法思想**

​		BFS 从起点 s 开始，先访问距 s 路径长为 1 的所有顶点，再访问路径长为 2 的所有顶点，依此类推。核心数据结构是 **队列**：每次取出队首，将其未访问的邻接点依次入队，并记录“层号”（即当前最短距离）。由于按层扩展，**首次到达目标顶点 t 时的层号就是 s→t 的最短路径长度**（前提：所有边权为 1 或无权重）。

**2、伪代码**

```
procedure BFS_ShortestPath(G, s, t):
    dist[⋅] ← ∞              // 距离表
    parent[⋅] ← null         // 前驱表，用于回溯路径
    Q ← empty_queue()
    dist[s] ← 0
    Q.enqueue(s)

    while Q not empty:
        u ← Q.dequeue()
        if u == t:           // 首次弹出即最短
            break
        for each neighbor v of u:
            if dist[v] == ∞: // 未访问
                dist[v] ← dist[u] + 1
                parent[v] ← u
                Q.enqueue(v)

    if dist[t] == ∞:
        return −1            // 不可达
    else:
        return dist[t], parent // 层数 + 前驱链
```

**3、复杂度**

- 时间：O(V + E)（每个顶点、每条边均常数次入队/出队）
- 空间：O(V)（队列 + 距离/前驱表）

**4、典型应用**

1. 无权图/等权图单源最短路径（社交网络“几度关系”）
2. 迷宫/网格最短步数（0-1 BFS 变种）
3. 状态空间搜索（水壶问题、8 数码、滑动拼图）

### （2）Dijkstra算法

**1、算法思想**

​		Dijkstra 是一种贪心算法，核心性质是：**在非负权图中，已确定最短距离的顶点，其最短距离不会再被后续松弛更新**。算法维护一个"未访问"集合，每一步从中取出当前 `dist` 最小的顶点标记为已访问，并用它的出边对邻居做**松弛操作**（relaxation：若经该点中转的路径比已知路径更短，则更新）。重复直到所有顶点被访问，或目标顶点被访问（可提前终止）。

**2、伪代码**

```
procedure Dijkstra(G, s):
    dist[⋅] ← ∞
    dist[s] ← 0
    visited[⋅] ← false
    parent[⋅] ← null
    PQ ← min_heap()           // 按 dist 值排序的优先队列
    PQ.push((0, s))

    while PQ not empty:
        (d, u) ← PQ.pop_min()
        if visited[u]: continue
        visited[u] ← true
        for each edge (u, v, w) in G.adj[u]:
            if not visited[v] and dist[u] + w < dist[v]:
                dist[v] ← dist[u] + w
                parent[v] ← u
                PQ.push((dist[v], v))

    return dist, parent
```

**3、复杂度**

- 朴素实现（邻接矩阵 + 逐一查找最小值）：O(V²)，适合稠密图
- 优先队列（二叉堆）+ 邻接表：O((V+E) log V)，常见工程实现
- 斐波那契堆优化：O(E + V log V)（理论最优，实践中常数较大，较少使用）

**4、注意事项**

- 权重必须**非负**，否则贪心性质被破坏，可能得到错误结果（详见「2、（3）负权图 vs. 正权图」）
- 若只需单目标最短路径，可在目标顶点被 `pop` 出（即标记 `visited`）时提前终止，无需算完全图

**5、典型应用**

1. 地图导航（路况权重非负）
2. 网络路由协议（如 OSPF、IS-IS）
3. 单源正权图最短路径的**通用首选**算法

### （3）Bellman-Ford 与 SPFA

**1、算法思想**

​		Bellman-Ford 基于动态规划/松弛思想：对图中**所有边**执行 **V-1 轮**松弛操作。由于最短路径最多经过 V-1 条边（若不存在负权环），V-1 轮后所有最短距离必然收敛。**第 V 轮**若仍能松弛成功，说明图中存在源点可达的负权环。

​		**SPFA（Shortest Path Faster Algorithm）** 是 Bellman-Ford 的队列优化版本：只对"距离刚被更新过的顶点"重新入队参与下一轮松弛，避免对已经稳定的顶点做无效计算。平均性能远优于朴素 Bellman-Ford，但在特殊构造的图（如网格图）上会退化到与 Bellman-Ford 同阶的最坏复杂度。

**2、伪代码（Bellman-Ford）**

```
procedure BellmanFord(G, s):
    dist[⋅] ← ∞
    dist[s] ← 0
    parent[⋅] ← null

    for i ← 1 to V - 1:
        for each edge (u, v, w) in G.edges:
            if dist[u] + w < dist[v]:
                dist[v] ← dist[u] + w
                parent[v] ← u

    // 第 V 轮：检测负权环
    for each edge (u, v, w) in G.edges:
        if dist[u] + w < dist[v]:
            return "存在负权环"

    return dist, parent
```

**伪代码（SPFA）**

```
procedure SPFA(G, s):
    dist[⋅] ← ∞
    dist[s] ← 0
    inQueue[⋅] ← false
    enqueueCount[⋅] ← 0       // 用于负环检测
    Q ← empty_queue()
    Q.enqueue(s); inQueue[s] ← true

    while Q not empty:
        u ← Q.dequeue(); inQueue[u] ← false
        for each edge (u, v, w) in G.adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] ← dist[u] + w
                parent[v] ← u
                if not inQueue[v]:
                    Q.enqueue(v); inQueue[v] ← true
                    enqueueCount[v] += 1
                    if enqueueCount[v] >= V:
                        return "存在负权环"

    return dist, parent
```

**3、复杂度**

- Bellman-Ford：O(V · E)
- SPFA：平均 O(k · E)（k 为较小常数），最坏情况仍为 O(V · E)

**4、典型应用**

1. 含负权边（但无负权环）的最短路径计算
2. 负权环检测（网络路由异常、金融三角套利检测，详见「2、（2）负权环」）
3. 差分约束系统求解（用不等式组建图，Bellman-Ford 判断是否有解）

### （4）Floyd-Warshall算法

**1、算法思想**

​		Floyd-Warshall 是多源最短路径的动态规划解法。核心状态定义：`dist[k][i][j]` 表示"**只允许经过编号 1~k 的顶点作为中转点**"时，i 到 j 的最短距离。状态转移只有两种选择：不经过 k（沿用 `dist[k-1][i][j]`），或经过 k（`dist[k-1][i][k] + dist[k-1][k][j]`）。由于第三维 k 只依赖上一轮，可以滚动压缩为二维数组，实现上直接原地更新即可。

**2、伪代码**

```
procedure FloydWarshall(G):
    dist ← G.adjacency_matrix()   // dist[i][j] = 边权；无边则为 ∞；dist[i][i] = 0

    for k ← 1 to V:
        for i ← 1 to V:
            for j ← 1 to V:
                if dist[i][k] + dist[k][j] < dist[i][j]:
                    dist[i][j] ← dist[i][k] + dist[k][j]

    // 负环检测：若存在某个 i 使 dist[i][i] < 0，说明图中存在负权环
    return dist
```

**3、复杂度**

- 时间：O(V³)
- 空间：O(V²)

**4、典型应用**

1. 稠密图的多源最短路径（一次计算，得到全部点对距离）
2. 小规模图（V 通常在几百以内）的全局距离表预计算
3. 判断图的传递闭包、检测负权环

### （5）Johnson算法

**1、算法思想**

​		Johnson 算法结合了 Bellman-Ford 与 Dijkstra，用于**稀疏图**的多源最短路径，效率优于 Floyd-Warshall。核心技巧是**重新赋权（reweighting）**：

1. 添加一个虚拟源点 q，向图中每个顶点连一条权重为 0 的边，用 Bellman-Ford 计算 q 到各顶点的最短距离 `h(v)`（同时完成负权环检测）
2. 用 `h(v)` 对原图所有边重新赋权：`w'(u,v) = w(u,v) + h(u) - h(v)`。可以证明这样得到的新权重 **全部非负**，且不改变任意两点间最短路径的相对顺序
3. 在新图上，对每个顶点分别跑一次 Dijkstra 求单源最短路径，再用 `h(u) - h(v)` 换算回原始权重下的真实距离

**2、复杂度**

- 时间：O(V² log V + V·E)（Dijkstra 用二叉堆实现），当图稀疏（E ≪ V²）时明显优于 Floyd-Warshall 的 O(V³)

**3、典型应用**

1. 大规模稀疏图的全局最短路径计算（如城市路网、大型稀疏社交/物流网络）
2. 图含负权边、但需要多源最短路径且规模较大、无法承受 O(V³) 的场景

### （6）A\* 算法

**1、算法思想**

​		A\* 是 Dijkstra 的启发式（heuristic）优化版本，在保持"贪心 + 松弛"框架的基础上，引入估价函数：

```
f(n) = g(n) + h(n)
```

- `g(n)`：起点到当前顶点 n 的**已知实际代价**（与 Dijkstra 中的 `dist` 相同）
- `h(n)`：当前顶点 n 到目标顶点的**估计代价**（启发函数，如欧几里得距离、曼哈顿距离）

​		优先队列按 `f(n)` 而非 `g(n)` 排序，使搜索优先朝目标方向扩展，从而减少无效探索。当启发函数 `h(n)` 满足**一致性（consistency，即 h(n) ≤ w(n, n') + h(n')）**时，A\* 保证能找到最优解，且效率通常远高于 Dijkstra。

**2、复杂度**

​		理论最坏情况与 Dijkstra 相同，为 O((V+E) log V)；但实践中由于启发函数的剪枝效果，实际访问的顶点数量大幅减少，尤其在空间（网格/地图类）问题上效果显著。

**3、典型应用**

1. 游戏寻路（网格地图、导航网格 NavMesh）
2. 机器人路径规划
3. 地图导航（用经纬度直线距离作为启发函数）

### （7）拓扑排序 + DP（DAG 专用）

**1、算法思想**

​		当图是**有向无环图（DAG）**时，可以先对图做拓扑排序，得到一个顶点的线性顺序，使得每条边都从排在前面的顶点指向排在后面的顶点。随后按拓扑序依次处理顶点，对每个顶点的出边做一次松弛（本质是一次 DP 转移）。由于拓扑序保证了"处理某顶点时，它的所有前驱都已经处理完毕"，所以只需一遍线性扫描即可得到所有最短路径——**即使含负权边也没问题**，因为图中无环，不会出现"绕环无限变小"的情况。

**2、伪代码**

```
procedure DAG_ShortestPath(G, s):
    order ← TopologicalSort(G)
    dist[⋅] ← ∞
    dist[s] ← 0
    parent[⋅] ← null

    for u in order:
        if dist[u] == ∞: continue   // 从 s 不可达，跳过
        for each edge (u, v, w) in G.adj[u]:
            if dist[u] + w < dist[v]:
                dist[v] ← dist[u] + w
                parent[v] ← u

    return dist, parent
```

**3、复杂度**

- 时间：O(V + E)（拓扑排序 O(V+E) + 一遍线性 DP），是所有单源最短路径算法中理论最快的一种
- 空间：O(V)

**4、典型应用**

1. 任务调度中的关键路径（Critical Path Method）计算
2. 编译器 / 构建系统中的依赖解析（如 Makefile、任务 DAG 的最优执行顺序）
3. 版本依赖图、工作流引擎中含负权（如"收益"类正向权重取负求最长路）的最优路径计算

## 4、算法对比总结

| 算法 | 适用场景 | 时间复杂度 | 支持负权 | 负环检测 |
| :--- | :--- | :--- | :--- | :--- |
| BFS | 单源、无权/等权图 | O(V+E) | 不支持 | 否 |
| Dijkstra | 单源、非负权图 | O((V+E)logV) | 不支持 | 否 |
| A\* | 单源、非负权、有明确目标点 | 最坏同 Dijkstra，实践更快 | 不支持 | 否 |
| Bellman-Ford / SPFA | 单源、含负权图 | O(VE)（SPFA 平均更快） | 支持 | 是 |
| 拓扑排序 + DP | 单源、DAG | O(V+E) | 支持（无环天然安全） | 不适用（无环） |
| Floyd-Warshall | 多源、稠密图/含负权 | O(V³) | 支持 | 是 |
| Johnson | 多源、稀疏图 | O(V²logV + VE) | 支持 | 是（内部依赖 Bellman-Ford） |

**选型口诀**：先看单源/多源，再看图是否有环（DAG 优先拓扑排序）、是否带权（无权用 BFS）、是否有负权（有负权用 Bellman-Ford/SPFA，无负权用 Dijkstra，有明确目标点可加启发函数升级为 A\*）；多源图则看是否稠密（稠密用 Floyd-Warshall，稀疏且非负权可用 Johnson 提速）。
