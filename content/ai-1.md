# 二、通用AI Agent与对话平台

这一类产品的核心是"自主规划+执行任务"，是从对话式AI迈向"帮你把事情做完"的过渡形态，按照是否支持本地部署分类。

**（1）支持完全本地部署的应用**

| 产品                                   | 开发方                      | 热度         | 定位与最新动态                                               |
| -------------------------------------- | --------------------------- | ------------ | ------------------------------------------------------------ |
| **Dify**                               | Langgenius (可完全本地)     | 开发者标杆   | 全球增长最快的开源LLM应用开发平台之一(GitHub 13.9万+ star)，定位可理解为"Coze的开源自托管版"：可视化工作流编排+RAG知识库+多模型管理。与Coze相比：Coze更适合零代码新手+国内生态一键发布，Dify更适合开发者+需要私有化部署/合规要求的团队。 |
| **N8N**                                | n8n GmbH (可完全本地)       | 自动化标杆   | 专为开发者与技术团队打造的开源工作流自动化工具，支持自托管。"可视化与代码的完美结合"：既支持拖拽式搭建，又允许在节点中嵌入JavaScript/Python代码进行精准控制。原生支持AI Agent工作流(内置LangChain集成)，缺点是与国内应用的集成不友好，比如钉钉飞书等办公应用。<br />支持Docker/npm本地部署，提供SSO、审计日志等企业级安全功能，对于构建AI自动化流程是不错的选择。 |
| **OpenClaw**(原Clawd→Clawdbot→Moltbot) | 独立开发者Peter Steinberger | 现象级开源   | 现象级产品，本地部署的个人AI助手，可接入WhatsApp/Telegram/飞书/Discord等IM，主打"数据全在自己手里"+长期记忆。有趣的是短期内三次改名，最终定名OpenClaw；️需注意今年2月曾出现一起失控事件(某基于该框架的Agent为执行环保指令擅自修改防火墙、封锁服务器端口)，部署时务必重视prompt injection等安全配置，不建议在核心生产力电脑上直接部署。 |
| **Hermes**                             | Nous Research               | 开源模型标杆 | Nous Research推出的开源大语言模型系列，专为本地部署和Agent场景优化。基于Llama架构微调，在工具调用、代码生成、指令遵循等方面表现优异，支持多种量化版本(GGUF/AWQ等)以适配不同硬件。社区活跃度高，是Dify、OpenClaw等本地Agent框架常用的底层模型之一，适合对数据隐私有要求且希望自主掌控模型能力的开发者。 |
| **OpenCode**                           | SST团队                     | 终端原生     | 开源的终端(TUI)AI编程助手，专为命令行工作流设计。支持本地运行，可接入多种LLM后端(包括本地Ollama模型)，提供代码补全、文件编辑、终端命令执行等能力。主打"无需离开终端"的沉浸式开发体验，轻量高效，适合**偏好CLI工作流的开发者**。 |

**（2）不支持完全本地部署（云端/SaaS为主）的应用**

| 产品       | 开发方         | 热度       | 定位与最新动态                                               |
| ---------- | -------------- | ---------- | ------------------------------------------------------------ |
| Manus      | 变更中         | 重大反转   | 支持网页和桌面版。2025年3月因通用Agent概念爆火，8个月ARR破1亿美元；2025年12月被Meta以约20亿美元收购；后因数据安全相关问题被叫停，正牵头中方资本以同等估值回购，交易仍在谈判中——目前归属尚未最终落定，笔记里不宜再写"已属于Meta"。采用多代理虚拟机架构，任务在独立云端沙盒中执行，不支持本地私有化部署。 |
| Coze(扣子) | 字节           | 零代码标杆 | 国内零代码/低代码Agent平台标杆，2.5版本起支持给每个Agent分配独立邮箱和身份、Agent间自主通信调用(形成"Agent网络")、多渠道长期记忆同步，并内置"扣子编程"(自然语言Vibe Coding)。纯云端SaaS服务，不支持本地部署，适合快速搭建和发布Agent到微信/飞书/豆包等渠道。 |
| Perplexity | Perplexity AI  | 搜索原生   | 以"直接给答案而非链接列表"起家的**AI搜索引擎**，衍生出Comet智能体浏览器(详见第九章)，可代为完成网页内的多步操作。纯云端服务，依赖Perplexity自有的搜索索引和推理基础设施 |
| AnyGen     | 字节(面向海外) | 出海新品   | 定位类似"字节版NotebookLM"的AI办公智能体工作空间，是国产大厂出海布局Agent赛道的代表——虽然主打海外用户界面和市场，但技术、团队均为国产背景，分类上容易被误认成纯"国外工具"，纯云端SaaS服务。字节系的海外布局确实多，包括Coze，以及trae海外版。 |

**使用提示**：这类通用Agent普遍具备文件读写、命令执行、网络访问等较高权限，配置时建议优先看官方安全指引，尤其是OpenClaw这类本地部署产品。

# 三、AI编程与开发Agent专题

2026年这块领域已经从"代码补全"彻底转向"自主编程Agent"，海外和国产阵营几乎同期爆发。

### (一)海外主流

三种形态并存，很多资深开发者是组合使用(IDE编辑器 + CLI/Agent跑重活)：

| 产品 | 开发方 | 形态 | 热度 | 核心特点 |
|---|---|---|---|---|
| **Claude Code** | Anthropic | CLI/Agent | 🔥编程标杆 | A社实力出圈不用多说，目前新出的Sonnet 5 在性价比上据说比 Opus 4.8强不少，但封号也是真的狠 |
| **OpenAI Codex** | OpenAI | CLI/Agent | 🔥编程标杆 | 集成进ChatGPT体系，云端沙箱异步执行任务，目前很多AI工具的一个主流方向 |
| **Cursor** | Anysphere | AI原生IDE | 🔥生态最强 | 类VS code的IDE，会集成最新的大厂先进模型，额度有限；但composer、Grok也不是不能用 |
| **Windsurf** | Cognition | AI原生IDE | ⭐协作流畅 | cursor最初的竞品，为不付费用户准备的免费体验额度有点少，至少用起来感觉比cursor少 |
| **Antigravity**(含Antigravity 2.0) | Google | Agent中心化IDE+多入口 | 🆕最具野心 | Google生态，基于 Gemini 的深度集成，多 Agent 协作实现 AI 自主规划和执行完整开发流程；<br />尝试在python中`import antigravity` |
| **Zed** | Zed Industries | AI原生IDE | ⭐性能派 | 主打启动和响应速度，AI能力紧跟但不算最前沿 |
| **GitHub Copilot** | GitHub(Microsoft) | 嵌入式插件 | ⭐生态元老 | 最早的AI编程工具，插件生态和IDE覆盖面仍是优势，现也扩展出Copilot Cloud Agent |

### (二)国产阵营

2025-2026年密集爆发：

| 产品 | 开发方 | 热度 | 核心特点 |
|---|---|---|---|
| **Trae** | 字节 | 🔥用户规模最大 | 国内首款AI原生IDE(2025年1月发布)，SOLO模式全自动编程，免费版可用度高，国内用户规模第一(约600万)，对中文技术栈(Taro/uni-app)支持最好 |
| **Qoder** | 阿里 | 🔥企业级标杆 | Agentic编程平台，AST语法树解析，"任务模式"端到端开发，企业级团队协作场景表现最"稳" |
| **通义灵码** | 阿里 | 🔥企业协作 | 功能最完善的国产工具之一，企业级成熟度高，是很多公司的主力工具 |
| **CodeBuddy** | 腾讯 | ⭐微信生态 | 全流程AI一体化工作台，专注微信小程序/公众号生态开发，已覆盖腾讯内部约1.2万工程师 |
| **文心快码(Comate)** | 百度 | ⭐前端刚需 | 多智能体协同见长，Figma设计稿转代码能力是差异化亮点，适合前端/UI还原场景 |
| **CodeGeeX** | 智谱 | ⭐免费首选 | 基础功能完全免费且质量不错，适合学生/个人开发者/预算有限场景 |

### (三)选型建议(按场景速查)

| 你的情况 | 推荐组合 |
|---|---|
| 个人开发者/学生，预算有限 | CodeGeeX/copilot(免费主力)+ Trae/claude/cursor免费额度 |
| 追求最强Agent自主编程能力，不差钱 | Claude Code 或 OpenAI Codex，搭配Cursor做日常编辑 |
| 微信生态/小程序开发为主 | CodeBuddy |
| 非技术型AI爱好者 | Chatgpt Plus会员订阅 |

**编程Agent vs 桌面/workflow Agent的边界**：核心任务是写代码/读代码库/测试/调试、目标用户是开发者 → 归入本章；核心任务是通用办公/文件处理/内容生成、目标用户是非技术用户 → 归入第八章(如WorkBuddy)。Claude Code虽也可做通用终端自动化，但核心定位仍是编程，归入本章。

**能力差距提醒**：国产工具在Agent自主性和多文件协同编辑上，目前仍落后Cursor/Claude Code一段距离，但DeepSeek V4等底层模型的推理能力正在快速缩小这个差距。

## (四)分镜与镜头提示词构建方法论

**基础公式**：`[镜头类型] + [主体描述] + [动作/表情] + [环境/光线] + [运镜方式] + [风格/氛围]`

**常用镜头类型(景别)**：
- 远景/大远景(Establishing Shot)：交代环境全貌，开场常用
- 全景(Wide Shot)：人物全身入镜
- 中景(Medium Shot)：人物腰部以上，对话场景常用
- 近景/特写(Close-up)：面部或局部细节，情绪表达
- 大特写(Extreme Close-up)：强调单一细节

**常用运镜提示词**：
- 推/拉(Push in / Pull out)：镜头靠近或远离主体
- 摇(Pan left/right)：机位不动，镜头左右转动
- 移(Tracking shot)：机位随主体平移
- 升降(Crane up/down)：垂直方向运镜，大场面开场常用
- 环绕(Orbit shot)：围绕主体360度旋转
- 手持晃动感(Handheld shake)：增加真实感/紧张感

**2026年新工具带来的实操变化**：
- 可灵3.0的"动作复制"：上传参考视频，让模型复制其中的运镜和角色动作，比纯文字描述精确度更高
- 可灵Canvas Agent：组织多个镜头、扩展场景，适合连续剧情的分镜串联
- Runway运动笔刷(Motion Brush)+相机路径控制：在画面上直接"画"出物体移动轨迹
- Runway Aleph编辑器：针对已生成素材做"改镜头"级别的二次编辑(改光线/天气/运镜)，不用重新生成

**实用建议**：新手先用纯文字prompt理解模型对镜头语言的理解程度，进阶后优先用"参考图/参考视频+简短文字"组合，比堆砌运镜术语更可控。
